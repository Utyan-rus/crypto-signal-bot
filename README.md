# Crypto Signal Bot (Telegram)

Бот, который по команде анализирует выбранную торговую пару и присылает
технический расклад **Long / Short / Neutral** с оценкой риска, стоп-лоссом
и тейк-профитом на основе индикаторов (EMA, RSI, MACD, Bollinger Bands, ATR,
дисбаланс стакана, funding rate для перпетуалов).

## Что бот НЕ делает
- Не подключается к твоему кошельку.
- Не размещает ордера и не торгует сам.
- Не гарантирует прибыль — это эвристика по публичным рыночным данным, а не предсказание будущего.

Торговля фьючерсами с плечом — высокий риск. Можно потерять больше, чем
внесено. Бот даёт только информационный сигнал; решение и ответственность
всегда твои.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Вставь токен в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=твой_токен
   EXCHANGE_ID=binance
   ```
3. Запусти:
   ```bash
   python bot.py
   ```

## Использование в Telegram

```
/start
/analyze BTC/USDT
/analyze ETH/USDT 4h
/watch BTC/USDT 1h       — бот сам напишет, когда сигнал станет сильным (≥60%)
/unwatch BTC/USDT
/mywatches
```

Таймфрейм необязателен (по умолчанию `1h`). Поддерживаются любые пары,
которые отдаёт выбранная биржа через ccxt (`EXCHANGE_ID` в `.env` — любая
биржа из списка ccxt, например `binance`, `bybit`, `okx`).

## Стратегии и защита от ошибок

По умолчанию используется **«Фильтр-тренд» (`guarded`)**. Он требует согласия EMA20/50/200, RSI в рабочей зоне, MACD, ADX не ниже 18 и объёма. Если фильтры расходятся, сигнал нейтральный. Нужны 220 закрытых свечей; незакрытая текущая свеча исключается.

`/strategy` показывает доступные стратегии. Старый выбор `eureka` автоматически заменяется на `guarded` один раз при первом запуске после обновления; после этого выбор стратегии сохраняется. Стратегии `eureka` и `yabloko` остаются доступными для сравнения.

`/scan [число рынков]` сканирует публичные Lighter perpetuals по 5m и 15m. После запуска также выполняется фоновая проверка примерно раз в 30 минут; повторные сигналы одного направления не дублируются. Это только уведомления, не исполнение ордеров.

Исторический Lighter-бэктест запускается в GitHub → Actions → **Lighter 90-day paper backtest**. Он учитывает оценочные комиссии и проскальзывание, ограничивает плечо 3x, пропускает позиции ниже минимального объёма и исключает рынки с покрытием истории ниже 90%. Фандинг не включён, а каждый рынок тестируется отдельно с виртуальным балансом 5 USDT — это не общий портфель.

## Как считается сигнал (коротко)

- **Тренд:** EMA20 vs EMA50
- **Моментум:** RSI, MACD-гистограмма
- **Mean reversion:** положение цены относительно полос Боллинджера
- **Поток ордеров:** дисбаланс bid/ask в стакане
- **Фандинг (для перпетуалов):** перекос в сторону лонгов/шортов
- **Риск:** ATR как % от цены → низкий/средний/высокий
- **Стоп/тейк:** 2×ATR и 3×ATR от цены входа (ориентировочно)

Логика в `analysis.py` — можно менять веса индикаторов под себя.

## Деплой с телефона, без ПК

Бот должен работать 24/7, значит нужен сервер. С телефона это делается через
GitHub (загрузить код в репозиторий прямо из браузера телефона) и платформу,
которая запускает код из GitHub автоматически.

**Честно про "бесплатно" в 2026:** по-настоящему бесплатного круглосуточного
хостинга для такого бота почти не осталось — большинство "free" тарифов либо
усыпляют сервис при простое (ломает бота), либо дают только пробный кредит на
старте. Самый простой рабочий вариант — Railway: пробный кредит бесплатно,
дальше бот обходится в среднем $1–5/мес, так как он почти всё время простаивает.

### Шаг 1: закинуть код на GitHub (с телефона)
1. Зайди на github.com в браузере телефона, зарегистрируйся / войди.
2. Создай новый репозиторий (New repository), например `crypto-signal-bot`.
3. На странице репозитория — "Add file" → "Upload files", загрузи все файлы
   из этой папки (`bot.py`, `exchange.py`, `analysis.py`, `requirements.txt`,
   `Procfile`, `.env.example`). **`.env` с реальным токеном не загружай.**

### Шаг 2: развернуть на Railway (с телефона)
1. Зайди на railway.app, войди через GitHub.
2. New Project → Deploy from GitHub repo → выбери свой репозиторий.
3. В настройках проекта (Variables) добавь:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - `EXCHANGE_ID` = `binance`
4. Railway сам поставит зависимости из `requirements.txt` и запустит
   `python bot.py` (команда уже указана в `Procfile`).
5. Через пару минут бот онлайн — пиши ему `/start` в Telegram.

### Альтернативы
- **Render.com** — похожий процесс (New → Background Worker → подключить
  GitHub-репо), но бесплатный тариф "засыпает" и ломает `/watch`; для
  надёжной работы нужен платный план (~$7/мес).
- **PythonAnywhere** — бесплатный тариф без оплаты вообще, но бот в режиме
  long-polling там держать постоянно нельзя на free-плане; подходит, только
  если переписать бота на webhook-режим — это отдельная доработка, скажи,
  если нужно.

## Проверки качества кода

GitHub Actions автоматически компилирует Python-модули и запускает регрессионные тесты при изменениях. Это проверяет техническую корректность, но не доказывает прибыльность стратегии.

## Расширение

- **Не** добавляй автоматическое исполнение ордеров без отдельного,
  тщательно протестированного риск-менеджмента (лимиты на позицию,
  дневной лимит убытка, kill switch).
